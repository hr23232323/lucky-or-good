# 000 Goal
Status: active
Problem: LLMs can propose trading strategies faster than anyone can check them, and backtests flatter almost everything. There is no small, honest, US-focused harness for running that loop and trusting the answer.
Outcome: a playground where any agent (Claude, Codex, a human) proposes strategies as files, and a frozen judge scores them with sealed periods, a full trial log, costs and look-ahead checks. First public experiment: "Lucky or good? I let Claude try 1,000 trading strategies", with human textbook strategies as baselines.
Done when: someone can clone the repo, point it at MarketParquet data, run an agent overnight, and publish a ledger that a skeptic can audit.
Notes: research, not financial advice. Data is licensed and never committed.
