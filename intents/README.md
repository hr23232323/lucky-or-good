# Intents

One small file per unit of work: what problem, what outcome, how we know it's done. Write the intent before the code. Keep each under a screen.

Template:

```
# NNN Title
Status: planned | active | done | dropped
Problem: one or two sentences.
Outcome: what exists when this is finished.
Done when: checks a reviewer can run.
Notes: decisions, links, anything deferred (prefer a GitHub issue for deferred work).
```

Status lives in the file. `PROGRESS.md` at the repo root is the one-glance summary.
